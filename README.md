# Susie64 PIC2 plugin

This software is a Susie x64 plugin for PIC2(.P2) format images.

## Thanks

The Susie I/F layer code was based on Masaru Miyasaka's Susie32 Pi Plug-in.
The PIC2 decoding specification was implemented with reference to [PIC2DOC.LZH](spec/PIC2DOC.LZH) and [PIC2SRC.LZH](spec/PIC2SRC.LZH).
